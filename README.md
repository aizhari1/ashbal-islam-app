# تطبيق أشبال الإسلام

## تحميل APK (من غير توكن Expo)

1. افتح: https://github.com/aizhari1/ashbal-islam-app/actions/workflows/build-android.yml
2. اضغط **Run workflow** → **Run workflow**
3. استنى لحد ما تبقى خضراء ✓
4. ادخل على التشغيل → تحت **Artifacts** حمّل **ashbal-islam-apk**
5. فك الضغط وثبّت `ashbal-islam.apk` على الموبايل

**مش محتاج** حساب Expo ولا توكن.
